# 2026-09-08 공개 사이트 SEO 점검

## 확인 범위와 근거

- 운영 사이트맵 630개 URL의 HTTP 상태, canonical, robots 메타, 제목과 설명을 읽었다.
- 이 범위에서 비정상 HTTP 상태, canonical 불일치, noindex 충돌, 제목·설명 누락 또는 중복은 발견되지 않았다.
- HTTP와 www 주소는 HTTPS 대표 주소로 301 이동했다.
- 홈의 WebSite·Person 구조화 데이터는 김승찬, kscold, 소개 페이지와 외부 프로필을 연결한다.
- 사이트맵 페이지들의 서버 HTML 링크를 대조했을 때 일부 Vault 문서는 들어오는 링크가 없었다.
  이는 해당 HTML 표본의 결과이며 전체 웹의 링크 부재나 구글 미색인을 뜻하지 않는다.
- 피드 API에는 새 글이 있지만 목록 초기 HTML에는 없는 상태를 운영에서 재현했다.
  서버 목록 캐시와 브라우저 initialData의 최신성 판단이 겹쳐 첫 방문 시 재조회가 발생하지 않았다.

## 구현한 개선

- 피드 목록을 요청 시 서버 렌더링하고 브라우저 재진입·포커스 복귀 시 다시 조회한다.
- 홈의 실명 블로그 제목을 화면에 표시하고 소개 페이지로 연결한다.
- 블로그·피드·Vault의 작성자 메타데이터와 소개 페이지 연결을 보강한다.
- Spring의 시간대 없는 발행 시각을 서울 기준으로 해석해 OG·JSON-LD·RSS에 UTC 오프셋을 명시한다.
- 포퐁 소개의 조직 로고와 프로젝트 참여자의 Person 식별자를 연결한다.
- `/notes`에서 사이트맵 기준에 맞는 공개 Vault 노트를 제목별 HTML 링크로 제공한다.
  제목 색인과 분량 투영만 사용하고 본문·그래프 전체는 조회하지 않는다.
  주소 없는 예전 문서는 기존 사이트맵처럼 제외한다.

## 백엔드와 Agent 점검

- 피드 공개 조회와 피드 사이트맵 투영은 PUBLIC 조건을 사용한다.
- Vault는 현재 공개 노트 도메인이며 제목·사이트맵 전용 투영 API가 있다.
- Agent 검색은 콘텐츠별 접근 필터와 원본 재검증을 사용한다.
  개인화된 채팅을 검색 색인 대상으로 만들거나 권한을 확대하지 않았다.
- Agent의 내부 프로필 문구에는 과거의 관심사 중심 소개가 남아 있다.
  이는 공개 웹 페이지의 메타데이터와 별개이며, 자동 생성 답변을 구글 순위 개선으로 간주하지 않는다.

## 검증과 남은 제한

- 날짜·피드 수정 후 로컬 브라우저 테스트 207개 통과, 2개 기존 스킵.
  기존 Admin Night의 서버 날짜·가상 브라우저 날짜 불일치 테스트 1개는 별도로 제외해 구분했다.
- 해당 커밋의 원격 CI도 207개 통과, 같은 Admin Night 테스트 1개 실패로 전체 상태는 실패다.
- 노트 목록 추가 후 공개 화면·사이트맵·피드·목록 정책 테스트 22개와 운영 빌드 통과.
- Search Console 실적, URL 검사, 수동 조치, 구글 선택 canonical과 실제 사용자 Core Web Vitals는 확인하지 못했다.
- 630개 원문의 정확성·독창성을 전수 편집한 것은 아니다. 분량 임계값도 콘텐츠 품질을 보증하지 않는다.
- 다음 측정은 Search Console에서 홈·소개 URL 검사 및 최근 28일과 이전 28일의
  `김승찬`, `김승찬 블로그`, `kscold` 검색어별 노출·클릭·평균 순위를 비교하는 것이다.
