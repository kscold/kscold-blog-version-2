# Agent 런타임 이전

대상은 Python 3.13.18, OpenAI SDK 3.39.0, Qdrant 서버·클라이언트 1.20.0이다.
이 문서는 배포 담당자가 적용할 절차이며, 코드 변경만으로 운영 데이터 이전이 수행되지는 않는다.

Python 3.13은 보안 수정 단계이지만 통합 이미지의 지정 버전이므로 최신 보안 패치를 사용한다.
일반 CPython 빌드를 사용하고 free-threaded 빌드는 사용하지 않는다.
설치 도구 pip·ensurepip는 Docker의 `build`/`verification` 단계에만 존재한다.
실행 이미지에서는 설치 도구 제거 후 의존성 검사와 전체 테스트를 수행한다.
실행 중인 이미지에 패키지를 설치하지 않고 이미지를 다시 빌드한다.

OpenAI SDK는 2를 거쳐 3으로 이전했다. SDK 3의 기본 전송 계층은 HTTPX2이며,
타임아웃은 SDK가 공개하는 `openai.Timeout`을 사용한다. 모델명과 Chat Completions,
임베딩, SSE 이벤트, 재시도 및 취소 계약은 유지한다.

Qdrant는 [공식 이전 절차](https://qdrant.tech/documentation/upgrades/)에 따라 서버를 먼저 올리고,
검증 후 클라이언트를 올린다. 저장 형식은 인접한 minor 버전 사이에서만 호환을 보장한다.

1. 쓰기를 정지하고 각 컬렉션 snapshot 및 현재 볼륨의 복구 가능한 백업을 확보한다.
2. 현재 1.19 운영 서버는 최신 1.19 패치인 1.19.2를 거쳐 1.20.0으로 올린다.
   1.19에서 `alt_api_key`를 사용했다면 1.20의 기본 internal authentication 변경 전에
   반드시 1.19.2를 거쳐 키 설정을 검증한다.
3. 기존 Compose의 1.10 데이터는 1.10→1.11→…→1.19→1.20 순서로 각 minor의 최신 패치를 거친다.
   새 이미지로 기존 1.10 볼륨을 곧바로 열지 않는다.
4. 단계마다 컬렉션 상태·벡터 수·실제 검색 결과를 확인한다. 기존 사용자 ID와 저장소 권한을 유지한다.
   일반 Compose는 기존 일반 이미지를, 운영용 Compose는 기존 unprivileged 이미지를 유지한다.
5. 서버 검증 후 새 Agent를 올리고 벡터 검색 결과에 MongoDB의 원본 문서 접근 권한과 폴더·콘텐츠 유형 필터가
   계속 적용되는지 확인한다. 벡터에만 남은 삭제·비공개 문서를 반환하지 않아야 한다.
6. 다운그레이드는 지원하지 않는다. 문제가 생기면 이전 이미지와 해당 단계 이전 백업으로 복구한다.

CI는 별도 Qdrant 서버의 임시 컬렉션으로 실제 검색을 검사한다.
`qdrant_server_smoke.py`는 `http://127.0.0.1:16333`만 허용하고 운영 주소를 기본값으로 사용하지 않는다.
